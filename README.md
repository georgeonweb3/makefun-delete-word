One word the entrant would erase from the dictionary forever, judged head to head in pairs. Free to enter.

The entry word (5 characters):

> never

Delete "never" and nobody can ever say "never" again — the deletion breaks its own rule the moment it lands.

## Run it

```sh
python3 main.py
```

This writes the word to `/output/entry.txt` (UTF-8, no trailing newline).
